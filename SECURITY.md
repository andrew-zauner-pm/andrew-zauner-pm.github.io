# Security and Confidentiality Guidelines

This repository is intended for a public GitHub Pages site.

Do not commit:

- Client names unless explicitly approved for public use
- Client data, screenshots, exports, reports, or implementation details
- Internal URLs, server names, database names, or environment details
- Credentials, API keys, tokens, passwords, certificates, or private keys
- Proprietary code copied from client or employer repositories

Recommended pre-publish check:

1. Search the repo for client names and project names.
2. Search for common secret patterns such as `password`, `token`, `secret`, `key`, `conn`, and `server`.
3. Confirm all examples are generic or publicly shareable.
4. Review screenshots and images before adding them.
5. Keep detailed case studies private unless they are approved for external publication.
